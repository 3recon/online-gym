# 온라인 헬스장

타자연습처럼 문장을 따라 치면 바벨이 올라가는 킬링타임 웹게임. 스쿼트·데드리프트·벤치프레스가 있다.
"넵 확인했습니다.", "첨부 파일 확인 부탁드립니다." 같은 직장인이 매일 치는 문장이 나오고,
한 문장 끝낼 때마다 한 칸씩 올라간다. 시간 안에 다 치면 성공. 옆에서 보면 그냥 일하는 중.
무거울수록 문장이 길어지고(메신저 답장 → 메일 → 보고서), 개수가 늘고, 목표 타속(타/분)이 올라간다.
들수록 근력이 붙어서 같은 무게가 쉬워진다. 근력은 세 운동이 같이 쓴다.
- 데드리프트: 같은 근력으로 1.25배 무게
- 벤치프레스: 0.75배 무게. 무게에 민감해서(`sens: 1.8`) 조금만 올려도 확 어려워진다. 무게 버튼도 2.5kg 단위
무게 설정·자동 증량·최고 기록·순위는 운동별로 따로다.
부장님이 오면 `ESC` → 문서 편집기로 위장. 따라 칠 문장은 부장님 검토 메모로 뜨고, 친 문장은 문서에 그대로 들어간다.

## 실행

```bash
npm start
```

http://localhost:3000 (포트는 `PORT` 환경변수로 변경)

의존성 없음. Node 18 이상.

## 배포

무료 배포(Cloudflare Workers + Supabase)는 [DEPLOY.md](DEPLOY.md) 참고. GitHub `main`에 푸시하면 Cloudflare가 `public` 폴더를 자동으로 올리고, `public/config.js`에 Supabase 값을 넣으면 온라인 기능이 켜진다.

## 구조

| 파일 | 내용 |
| --- | --- |
| `server.js` | 정적 파일 + 실시간 피드(SSE). 접속자 수, 랙 위 사람, 성공/깔림 소식, 응원, 오늘/역대 순위 |
| `public/app.js` | 게임 로직 (문장 목록 `PHRASES`, 타속 판정, 한글 조합 처리, 근력 성장, 피드, 순위) |
| `public/figure.js` | 운동하는 사람 SVG. 스쿼트·데드는 정면, 벤치는 위에서 비스듬히 내려다본 모습(바벨이 들릴수록 커지고 그림자와 멀어짐). 원판 쌓이고 봉이 휨 |
| `public/boss.js` | 부장님 모드 (가짜 문서 편집기) |
| `public/net.js` | 서버 연결. Supabase(배포) → 로컬 node 서버 → 혼자 연습 모드 순으로 시도 |
| `public/config.js` | Supabase 주소·키, 애드센스 값 |
| `public/ads.js` | 광고 (config에 값이 있을 때만) |
| `public/guide.html` 등 | 하는 법 · 소개 · 개인정보처리방침 |
| `supabase/schema.sql` | Supabase에 한 번 붙여넣는 테이블·함수 (조작 방지 포함) |
| `wrangler.toml`, `worker.js` | Cloudflare 배포 설정. `public`을 사이트로 올리고, Supabase가 잠들지 않게 하루 한 번 깨움 |
| `public/shared.js` | 닉네임 단어, 응원 문구 (서버와 같이 씀) |

## 메모

- 개인 기록은 브라우저 localStorage, 순위는 서버의 `data/state.json`에 운동별로 저장된다. 운동 구분 전의 예전 기록은 스쿼트로 옮겨진다.
- 서버 없이 `public/`만 정적 호스팅해도 혼자 연습 모드로 돌아간다.
- 기록은 클라이언트가 보내는 값을 그대로 믿는다(무게 범위·요청 간격만 검사). 순위를 진지하게 운영하려면 서버 쪽 검증이 더 필요하다.
- 문장은 `public/app.js`의 `PHRASES`(short/mid/long)에 추가하면 된다. 끝에 마침표·느낌표를 붙여야 Enter 없이 자동으로 넘어간다.
- 밸런스는 `liftParams()`(문장 수·길이 단계·목표 타속), `EXTRA_TIME`(여유 시간), 운동별 설정 `EX`(factor·sens·무게 단위)에서 조절.
